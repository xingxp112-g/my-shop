---
description: 读取计划文件并执行指定任务，完成后标记任务完成并提示 commit
---

$ARGUMENTS 的格式为：`<计划文件路径> <任务编号>`，例如：`docs/security-refactor-plan.md 2`

请按以下流程执行：

**第一步：读取并理解任务**

读取计划文件 `$ARGUMENTS` 中第一个参数指定的路径，找到第二个参数对应的任务编号。
提炼出：
- 任务标题
- 涉及的文件
- 具体要做什么
- 风险提示

用简洁的语言告诉我任务内容，然后问我："确认开始执行吗？"

**第二步：等待确认后执行**

收到我的确认后，按任务描述进行代码改动。改动完成后告知结果（改了哪些文件、哪些行）。

**第三步：标记完成并提示 commit**

将计划文件中该任务的 `[ ]` 改为 `[x]`，然后**立即**提示我运行 git commit，建议的 commit message 格式：
```
<type>: <任务标题简述>
```
